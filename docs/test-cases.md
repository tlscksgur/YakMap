# Yak-Map Test Cases

이 문서는 약-맵 QA 기준 테스트 케이스와 체크리스트입니다. 현재 자동화 테스트는 핵심 흐름과 회귀 방지를 담당하고, 브라우저 권한, 외부 앱 실행, 실제 푸시 수신, 카메라 촬영 품질처럼 환경 의존성이 큰 항목은 수동 검증 대상으로 관리합니다.

## Coverage Policy

| 구분 | 의미 |
| --- | --- |
| Automated | `npm test`에서 코드/계약/로직 수준으로 검증 |
| Manual | 실제 브라우저, 권한, 외부 앱, 기기 상태가 필요한 수동 검증 |
| Gap | 명세에는 있으나 현재 MVP 기능 범위를 벗어나 추가 구현 필요 |
